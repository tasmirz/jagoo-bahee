Two defects, found only by deploying it

Both were invisible to a suite of 823 passing tests. Each needed a topology the in-process harness could not express — which is the most transferable thing this work produced.

A stale tree head read as a log fork

Fixed · 17→18

Four code paths observe a peer's signed tree head with no ordering between them. An older reading arriving after a fresher one looked like a tree that had shrunk — the single strongest tamper signal the system has — and irrecoverably BLOCKED two honest peers. The bridge then correctly refused to bridge, and every downstream symptom was a faithful report of a state produced by a false accusation.

The rule: a check that can block a peer must first establish that its evidence is current, not just that it is attributable. If the payload carries no ordering claim, the comparison cannot honestly be made.

One unreachable peer stalled delivery to every reachable one

Fixed · 18→19

The outbox drained peers serially, with no deadline. A severed link blackholes rather than refuses, so the connection attempt to the cut-off peer neither succeeded nor errored — and every peer behind it in the same pass waited, including the bridge whose entire purpose is to route around that partition. A node with three peers degraded to the availability of its worst peer instead of its best.

The tell: every queued row sat at attempts: 0 while overdue by 150 seconds. Retries that fail tell you about the destination; work never attempted tells you about the scheduler.

Why it survived this long: a two-node deployment has no head of line to block. It needed three peers, one of which goes unreachable while the others stay up.

Malformed input returned HTTP 500 — and the error path was the amplifier

Fixed

Flooding a live node with 3000 mutated envelopes returned 8 responses as HTTP 500 with a protobuf stack trace, because the write endpoint decoded untrusted bytes outside the pipeline purely to label a metric. A caller could choose how fast the node filled its own disk. Fixing it also took rejection throughput from 440 to 730 req/s — the node had been spending the difference constructing stack traces.

The anonymous option went missing, and the next build named all three authors

Guarded now

The sweep we threw away

A parameter sweep is the shape of evidence that looks rigorous while being worthless. This one was, and only an accident caught it.

The same configuration disagreed with itself by 5×

Discarded

Eight configurations of chain length and drain interval were measured and every number discarded. Runs degraded monotonically as the sweep proceeded — delivery fell from 100% to 88%, maxima reached 180 s, and the linear fit's R² collapsed from 0.98 to 0.33 with a 67-second intercept.

The evidence was a configuration that happened to repeat: an identical four-node, 500 ms run measured 1348 ms at the first hop early in the sweep and 6630 ms later. Recreating the host returned it to 888 ms at 100% delivery. The varying quantity was host contention, not the parameter.

That repeat was unplanned. A sweep visiting each configuration once has no internal control and would have shipped three significant figures of nonsense. Every sweep from here carries a deliberate duplicate, checked against itself before anything else is read.

Both ratios go in the paper, not just the flattering one

Discipline

On protocol overhead the ratio is 19.5×–25.9×. But compression erases most of it: ActivityPub gzips to a 1074 B median while our envelopes do not compress at all — a random 64‑byte signature is incompressible, and gzip makes all three of ours larger. The compressed comparison is 4.4×–6.9×.

The first gzip figure computed was wrong in our favour, because the signature had been padded with zero bytes. Quoting only the uncompressed ratio is what a reviewer finds before disbelieving everything else in the paper.

ActivityPub is also charged nothing for authentication here, while our figures include a signature that makes the envelope verifiable at rest. A structurally fair comparison would widen the gap, not narrow it.
